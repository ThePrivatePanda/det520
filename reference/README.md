# Reference material — not published

Working reference for maintaining the site. Only `src/` is deployed, so nothing
in this directory is served at det520.privatepanda.co.

Keep it that way — do not move any of it into `src/`. `Website Checklist.txt`
(the AF IMT 2519 Public Website Quality Assurance Checklist, transcribed from
the scanned original) lists cadre names, emails, and phone numbers in Section II.
Publishing it would break items 8 and 10 of the checklist itself.
